## 1. 环境准备与安装

### 1.1 系统要求

- **操作系统**: Windows 10/11, macOS 10.15+, Linux
- **Node.js**: 18.0 或更高版本
- **MySQL**: 8.0 或更高版本
- **浏览器**: Chrome 90+, Firefox 88+, Edge 90+

### 1.2 安装Node.js

访问 [Node.js官网](https://nodejs.org/) 下载并安装LTS版本。

验证安装：
```bash
node -v   # 应显示 v18.0.0 或更高
npm -v    # 应显示 9.0.0 或更高
```

### 1.3 安装MySQL

访问 [MySQL官网](https://dev.mysql.com/downloads/mysql/) 下载并安装MySQL 8.0。

安装过程中记住设置的root密码，后续配置需要使用。

### 1.4 克隆项目

```bash
git clone https://github.com/yourusername/SmartCampus.git
cd SmartCampus
```

### 1.5 安装项目依赖

```bash
# 方式1：一键安装所有依赖（推荐）
npm run install:all

# 方式2：分别安装
cd backend-api && npm install
cd ../frontend-web-admin && npm install
cd ../mobile-app && npm install
```

## 2. 项目配置

### 2.1 创建数据库

打开MySQL命令行或MySQL Workbench，执行：

```sql
CREATE DATABASE smart_campus CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2.2 配置后端环境变量

复制 `backend-api/.env.example` 为 `backend-api/.env`，然后编辑配置：

```env
# ==================== DeepSeek API ====================
# 用途：AI对话、AI学习助手、AI写作助手、情感分析、AI科普等所有AI功能
# 申请地址：https://platform.deepseek.com/
DEEPSEEK_API_KEY=你的DeepSeek_API_Key
DEEPSEEK_API_URL=https://api.deepseek.com/v1/chat/completions

# ==================== Umi-OCR 本地服务 ====================
# 用途：图片文字识别（OCR）
# 项目地址：https://github.com/hiroi-sora/Umi-OCR
# 本地服务地址（默认）
UMI_OCR_URL=http://127.0.0.1:1224/api/ocr

# ==================== 数据库配置 ====================
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=你的MySQL密码
DB_NAME=smart_campus

# ==================== 服务器配置 ====================
PORT=3000
JWT_SECRET=your-secret-key-change-this-in-production

# ==================== AI使用限制 ====================
AI_CHAT_DAILY_LIMIT=100
AI_OCR_DAILY_LIMIT=50
```

### 2.3 获取DeepSeek API Key

1. 访问 [DeepSeek开放平台](https://platform.deepseek.com/)
2. 注册并登录账号
3. 进入"API密钥"页面
4. 创建新的API密钥
5. 复制密钥并填入 `.env` 文件的 `DEEPSEEK_API_KEY`

### 2.4 安装Umi-OCR（可选）

如果需要使用OCR文字识别功能：

1. 访问 [Umi-OCR GitHub](https://github.com/hiroi-sora/Umi-OCR)
2. 下载最新版本
3. 解压并运行 `Umi-OCR.exe`
4. 在设置中开启"HTTP服务"，端口设置为 `1224`

### 2.5 初始化数据库

```bash
cd backend-api
npm run init:db
```

成功后会显示：
```
✅ 数据库初始化成功！
✅ 已创建测试账号：
   管理员: admin / admin123
   教师: teacher1 / teacher123
   学生: student1 / student123
```

## 7. 常见问题解答

### 7.1 安装与配置问题

**Q: npm install 报错怎么办？**

A: 尝试以下解决方案：
```bash
# 清除npm缓存
npm cache clean --force

# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
npm install
```

**Q: MySQL连接失败？**

A: 检查以下配置：
1. MySQL服务是否启动
2. `.env` 文件中的数据库配置是否正确
3. 数据库用户是否有权限
4. 防火墙是否阻止连接

**Q: 端口被占用怎么办？**

A: 
```bash
# Windows查看端口占用
netstat -ano | findstr :3000

# 结束进程
taskkill /PID 进程号 /F

# Linux/Mac查看端口占用
lsof -i :3000

# 结束进程
kill -9 进程号
```

### 7.2 AI功能问题

**Q: DeepSeek API调用失败？**

A: 检查以下内容：
1. API Key是否正确配置
2. API Key是否有余额
3. 网络是否正常
4. API URL是否正确
5. 查看后端日志确认错误信息

**Q: OCR识别不准确？**

A: 提高识别准确率的方法：
1. 确保图片清晰度足够
2. 图片光线充足，避免反光
3. 文字排列整齐
4. 避免复杂背景
5. 建议分辨率1920x1080以上

**Q: Umi-OCR服务无法连接？**

A: 
1. 确认Umi-OCR已启动
2. 检查HTTP服务是否开启
3. 确认端口为1224
4. 检查防火墙设置

### 7.3 功能使用问题

**Q: 课表显示为空？**

A: 
1. 确认已初始化数据库
2. 检查是否有课程安排
3. 确认学生/教师信息正确
4. 刷新页面重试

**Q: 文件上传失败？**

A: 
1. 检查文件大小（建议<10MB）
2. 检查文件格式是否支持
3. 检查uploads目录权限
4. 查看后端日志错误信息

**Q: WebSocket连接失败？**

A: 
1. 确认后端服务已启动
2. 检查防火墙设置
3. 检查浏览器是否支持WebSocket
4. 尝试刷新页面重新连接

### 7.4 性能优化

A:

3. 优化图片大小

## 常见操作场景

### 场景1：学生查看今日课程并导航到教室

1. **移动端操作**:
   - 打开App，首页显示今日课程
   - 点击即将上课的课程
   - 查看课程详情（时间、地点、教师）
   - 点击"导航"按钮
   - 系统打开校园地图，显示最优路线
   - 跟随导航前往教室

2. **系统交互**:
   - 移动端请求今日课程数据
   - 后端查询数据库返回课表
   - 点击导航时获取当前位置
   - 计算到教室的最优路线
   - 实时更新导航信息

### 场景2：教师发起课堂签到

1. **Web端操作**:
   - 教师登录Web管理后台
   - 进入"我的课程"
   - 选择当前正在上的课程
   - 点击"发起签到"
   - 设置签到时长（如5分钟）
   - 点击"开始签到"

2. **移动端操作**:
   - 学生收到签到通知
   - 打开App进入签到页面
   - 点击"签到"按钮
   - 系统验证位置（可选）
   - 完成签到

3. **Web端查看**:
   - 教师实时查看签到情况
   - 查看已签到/未签到学生
   - 签到时间结束后查看统计

### 场景3：学生预约空闲教室

1. **移动端操作**:
   - 打开App
   - 点击"空闲教室"
   - 选择日期和时间段
   - 设置筛选条件（容量、设备）
   - 查看空闲教室列表
   - 选择合适的教室
   - 点击"预约"
   - 填写预约信息（用途、人数）
   - 提交预约

2. **Web端审核**:
   - 管理员收到预约通知
   - 查看预约详情
   - 审核通过或拒绝
   - 填写审核意见

3. **移动端接收**:
   - 学生收到审核结果通知
   - 查看预约详情
   - 预约成功后可查看预约记录

### 场景4：管理员查看数据大屏

1. **Web端操作**:
   - 管理员登录
   - 点击"数据大屏"
   - 查看实时数据
     - 在校人数
     - 教室使用率
     - 能耗数据
     - 人流热力图
   - 可切换不同时间段
   - 可导出数据报表
   - 支持全屏展示

### 场景5：学生使用语音助手

1. **移动端操作**:
   - 打开App
   - 点击语音助手图标或长按悬浮按钮
   - 说出指令："明天上午有什么课？"
   - 系统语音识别并处理
   - 语音回复："明天上午有两节课，第一节是高等数学..."
   - 同时显示课表详情
   - 可继续对话："帮我导航到教室"

## 常见问题解答

### Q1: 忘记密码怎么办？

**A**: 
- 联系管理员重置密码
- 或使用"忘记密码"功能（需要绑定邮箱/手机）

### Q2: 课表不显示怎么办？

**A**: 
1. 检查网络连接
2. 刷新页面/下拉刷新
3. 确认是否已选课
4. 联系管理员检查课表数据

### Q3: 签到失败怎么办？

**A**: 
1. 检查是否在签到时间内
2. 检查网络连接
3. 确认位置权限已开启（如有位置验证）
4. 联系教师说明情况

### Q4: 教室预约被拒绝？

**A**: 
- 查看审核意见
- 可能原因：
  - 教室已被占用
  - 预约时间冲突
  - 预约信息不完整
- 重新选择其他教室或时间

### Q5: 收不到通知？

**A**: 
1. 检查通知权限是否开启
2. 检查消息设置中是否关闭了某类通知
3. 检查网络连接
4. 重新登录App

### Q6: 语音助手无法使用？

**A**: 
1. 检查麦克风权限
2. 检查网络连接
3. 确保在安静环境下使用
4. 清晰地说出指令

### Q7: 导航不准确？

**A**: 
1. 检查GPS定位权限
2. 在室外开阔地带使用
3. 等待GPS信号稳定
4. 重新定位

### Q8: 数据不同步？

**A**: 
1. 检查网络连接
2. 刷新页面
3. 退出重新登录
4. 清除缓存

### Q9: 如何修改个人信息？

**A**: 
- Web端：首页 → 个人中心 → 编辑资料
- 移动端：我的 → 个人信息 → 编辑

### Q10: 如何导出数据？

**A**: 
- 大部分数据列表页面都有"导出"按钮
- 支持导出为Excel或PDF格式
- 管理员权限可导出更多数据
