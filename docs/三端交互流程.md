# 三端交互流程说明

> 管理员 / 教师 / 学生 在各模块中的角色与交互流程

## 1. 教学质量评估流程

```
管理员                          教师                          学生
  │                              │                              │
  ├─ 创建考试                    │                              │
  ├─ 配置考试科目                │                              │
  │                              │                              │
  │                              ├─ 导入成绩 ─────────────→     │
  │                              │   (Excel/手动录入)           │
  │                              │                              │
  │                              ├─ 查看班级学情分析            │
  │                              │   (各科统计、薄弱科目)       │
  │                              │                              │
  ├─ 查看年级学情分析            │                              │
  │   (各班对比)                 │                              │
  │                              │                              │
  │                              │                              ├─ 查看自己的成绩
  │                              │                              ├─ 查看学情分析
  │                              │                              │   (雷达图、趋势)
  │                              │                              │
  │                              ├─ 识别薄弱学生 ─────────────→ ├─ 收到学习建议
```

## 2. 学生成长档案流程

```
管理员                          教师                          学生
  │                              │                              │
  │                              ├─ 添加心理健康记录            │
  │                              │   (测评日期、情绪指数)       │
  │                              │                              │
  │                              ├─ 添加学期评语                │
  │                              │   (手写 / AI生成)            │
  │                              │                              │
  │                              │                              ├─ 添加技能记录
  │                              │   ←── 待教师认证 ──────────┤   (学术/体育/艺术)
  │                              ├─ 认证学生技能                │
  │                              │                              │
  │                              │                              ├─ 添加荣誉记录
  │                              │   ←── 待教师认证 ──────────┤   (竞赛获奖等)
  │                              ├─ 认证学生荣誉                │
  │                              │                              │
  ├─ 查看班级成长档案            │                              │
  │   (全班学生概览)             │                              │
  │                              │                              │
  │                              ├─ 查看学生档案总览            │
  │                              │   (技能/荣誉/心理/评语)      │
  │                              │                              │
  │                              │                              ├─ 查看自己的成长档案
  │                              │                              │   (只读心理/评语)
```

## 3. 权限矩阵

| 操作 | 管理员 | 教师 | 学生 |
|------|:------:|:----:|:----:|
| 考试管理 (CRUD) | 全部 | 自己创建的 | - |
| 成绩导入 | 全部 | 自己班级 | - |
| 成绩查看 | 全部 | 自己班级 | 仅自己 |
| 班级学情分析 | 全部 | 自己班级 | - |
| 年级学情分析 | 全部 | - | - |
| 学生学情分析 | 全部 | 自己学生 | 仅自己 |
| 班级管理 | 全部 | - | - |
| 技能/荣誉 添加 | 全部 | 全部 | 自己的(待审核) |
| 技能/荣誉 审核 | 全部 | 全部 | - |
| 心理健康 读写 | 读写 | 读写 | 只读 |
| 评语 读写 | 读写 | 读写 | 只读 |
| 成长档案 查看 | 全部 | 自己班级 | 仅自己 |
