# 三端交互流程说明

> 管理员 / 教师 / 学生 在各模块中的角色与交互流程

## 1. 教学质量评估流程

```
管理员                          教师                          学生
  │                              │                              │
  ├─ 创建考试                    │                              │
  ├─ 配置考试科目                │                              │
  │                              │                              │
  │                              ├─ 导入成绩 ─────────────→     │
  │                              │   (Excel/手动录入)           │
  │                              │                              │
  │                              ├─ 查看班级学情分析            │
  │                              │   (各科统计、薄弱科目)       │
  │                              │                              │
  ├─ 查看年级学情分析            │                              │
  │   (各班对比)                 │                              │
  │                              │                              │
  │                              │                              ├─ 查看自己的成绩
  │                              │                              ├─ 查看学情分析
  │                              │                              │   (雷达图、趋势)
  │                              │                              │
  │                              ├─ 识别薄弱学生 ─────────────→ ├─ 收到学习建议
```

## 2. 学生成长档案流程

```
管理员                          教师                          学生
  │                              │                              │
  │                              ├─ 添加心理健康记录            │
  │                              │   (测评日期、情绪指数)       │
  │                              │                              │
  │                              ├─ 添加学期评语                │
  │                              │   (手写 / AI生成)            │
  │                              │                              │
  │                              │                              ├─ 添加技能记录
  │                              │   ←── 待教师认证 ──────────┤   (学术/体育/艺术)
  │                              ├─ 认证学生技能                │
  │                              │                              │
  │                              │                              ├─ 添加荣誉记录
  │                              │   ←── 待教师认证 ──────────┤   (竞赛获奖等)
  │                              ├─ 认证学生荣誉                │
  │                              │                              │
  ├─ 查看班级成长档案            │                              │
  │   (全班学生概览)             │                              │
  │                              │                              │
  │                              ├─ 查看学生档案总览            │
  │                              │   (技能/荣誉/心理/评语)      │
  │                              │                              │
  │                              │                              ├─ 查看自己的成长档案
  │                              │                              │   (只读心理/评语)
```

## 3. 课程与课表流程

```
管理员                          教师                          学生
  │                              │                              │
  ├─ 维护课程 (增删改)           ├─ 维护课程 (增改)             │
  │                              │                              │
  ├─ 排课 (新增/修改/删除)       ├─ 冲突预检                    │
  │   (班级/教师/教室)           │   (排课前校验)               │
  │                              │                              │
  ├─ 清空班级课表                │                              │
  │                              │                              │
  │                              ├─ 查看周课表 ─────────────→   ├─ 查看本班课表
  │                              │   (按班级/教师/教室)         │   (周网格)
  │                              │                              │
  │                              │                              ├─ 查看课程列表/详情
  │                              │                              ├─ 学生选课 (enroll)
  │                              │                              │
  │                              ├─ 查看课程学生名单            │
```
