
## 三端交互流程说明

### 1. 课程管理流程

```
管理员（Web）                    教师（Web/移动端）              学生（移动端）
    │                                │                            │
    ├─ 创建课程                      │                            │
    │                                │                            │
    ├─ 分配教师 ────────────────────→│                            │
    │                                │                            │
    │                                ├─ 上传课件                  │
    │                                │                            │
    │                                ├─ 发布通知 ────────────────→│
    │                                │                            │
    │                                │                            ├─ 接收通知
    │                                │                            │
    │                                │                            ├─ 查看课件
    │                                │                            │
    ├─ 排课（分配时间、教室）        │                            │
    │                                │                            │
    │                                │                            ├─ 查看课表
    │                                │                            │
    │                                ├─ 发起签到                  │
    │                                │                            │
    │                                │                            ├─ 课堂签到
    │                                │                            │
    │                                ├─ 查看签到结果              │
    │                                │                            │
    │                                ├─ 录入成绩                  │
    │                                │                            │
    │                                │                            ├─ 查看成绩
```

### 2. 教室预约流程

```
学生（移动端）                   系统（后端）                    管理员（Web）
    │                                │                            │
    ├─ 查询空闲教室 ────────────────→│                            │
    │                                │                            │
    │                                ├─ 返回空闲教室列表          │
    │                                │                            │
    ├─ 提交预约申请 ────────────────→│                            │
    │                                │                            │
    │                                ├─ 通知管理员 ──────────────→│
    │                                │                            │
    │                                │                            ├─ 审核预约
    │                                │                            │
    │                                ├─ 审核结果 ←────────────────┤
    │                                │                            │
    ├─ 接收审核通知 ←────────────────┤                            │

    ├─ 使用教室                      │                            │
    │                                │                            │
    ├─ 签到确认 ────────────────────→│                            │
```


### 5. 课前提醒流程（位置感知）

```
学生（移动端）                   系统（后端）                    定位服务
    │                                │                            │
    ├─ 开启位置感知提醒              │                            │
    │                                │                            │
    │                                ├─ 定时检查即将上课的课程    │
    │                                │                            │
    │                                ├─ 获取学生位置 ─────────────→│
    │                                │                            │
    │                                ├─ 当前位置 ←─────────────────┤
    │                                │                            │
    │                                ├─ 计算距离教室的距离        │
    │                                │                            │
    │                                ├─ 判断是否需要提醒          │
    │                                │  （距离>100米 && 课前15分钟）│
    │                                │                            │
    ├─ 接收课前提醒 ←────────────────┤                            │
    │  "您的课程即将开始，请前往XX教室" │                            │
    │                                │                            │
    ├─ 点击导航 ────────────────────→│                            │
    │                                │                            │
    │                                ├─ 规划路线                  │
    │                                │                            │
    ├─ 开始导航 ←────────────────────┤                            │
```

### 6. 实时数据同步

系统使用 WebSocket 实现实时数据同步：

**实时同步的数据**:
- 课堂签到状态
- 食堂人流数据
- 教室使用状态
- 通知推送
- 活动报名人数

**同步流程**:
```
客户端（Web/移动端）             WebSocket服务器               数据库
    │                                │                            │
    ├─ 建立WebSocket连接 ───────────→│                            │
    │                                │                            │
    │                                ├─ 数据变化监听 ─────────────→│
    │                                │                            │
    │                                ├─ 数据更新 ←─────────────────┤
    │                                │                            │
    ├─ 接收实时数据 ←────────────────┤                            │
    │                                │                            │
    ├─ 更新UI显示                    │                            │
```
